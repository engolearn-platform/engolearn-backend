# Speaking V2 runtime flows

1. Availability checks Topic’s learner gate and the released profile, then reads Quota. Create pins a snapshot and reserves the owner slot before inserting the INITIALIZING session. Replacement validates admission before closing the prior session and transfers the slot after ENDED.
2. Opening work claims a durable token, generates structured text or uses the pinned fallback, then commits it before sending. Cartesia can add a protected WAV independently. Opening uses neither turn counts nor measured usage. Recovery reclaims an expired opening attempt and resolves interrupted audio to text fallback.
3. An authenticated REST caller can obtain a one-use WebSocket ticket. The upgrade enforces the Origin and binds the consumed ticket to the existing P1 lease and epoch. Disconnect cancels a receiving turn without finalizing it. A sealed turn remains independently settleable after reconnect or takeover.
4. `START_TURN` reserves a sequence and the socket sends `TURN_ACCEPTED` before opening a per-turn AssemblyAI stream. Only correctly framed, contiguous PCM for the accepted turn is admitted. `END_TURN` seals the turn and acknowledges TRANSCRIBING. The bounded worker stores the original recording as protected mono PCM WAV and keeps the audio evidence independent of provider outcomes. The original STT text commits before generation.
5. Generation uses the system prompt, pinned Topic context, current memory, up to the last five completed exchanges, and the current original transcript with available metadata. Reply and accepted optional sections commit before delivery. The next turn gets memory replayed from ordered committed deltas if the cached watermark is stale. A failed generation can use the stored transcript once under the same turn ID.
6. The server records when it sends committed text. A Cartesia failure leaves the reply available. A WAV reply uses serialized SPK2 messages with correlation and measured duration. Interrupted delivery retains text and any already stored media. Recovery does not regenerate a committed reply.
7. One immutable charge uses available learner speech, successful processing wait capped at 10 seconds and the duration of WAV delivered to the socket. It rounds the sum up once. The command carries the first accepted recording time as occurrence provenance. Quota uses its first successful recording time for the Asia/Ho_Chi_Minh day and retains that same outcome on replay. The quota command and acknowledgment can replay independently of provider work. An eligible failed generation holds its charge open until retry completes, the learner starts a new turn, or the session closes.
8. Closing blocks new admission and fences unfinished work at the cutoff. An already committed reply can complete delivery on the existing lease. Recovery expires sessions, archives terminal markers, settles stale work and reconciles owner reservations.

## Assessment handoff

`FinalizedSpeakingAudio` publishes the sealed original PCM with session ID, turn ID and sequence. The event carries a MediaManagement ID when storage succeeded and still supplies PCM if it failed. The listener should enqueue bounded work. For restart recovery, `SpeakingRuntime.finalizedAudioEvidence(sessionId, turnId)` returns the sealed turn and its protected learner Media reference when present. Apply retention checks before resolving the Media reference internally. Failed and skipped finalized turns remain eligible for independent acoustic evidence policy.

`GeminiSpeakingGeneration.generateStructured(system, data, input, schema, timeout, maxOutputTokens)` returns raw text for a separately supplied schema and prompt. It shares configured credentials and lazy clients with conversation. Language assessment owns its own schema, history, validation, timeout and scoring.
